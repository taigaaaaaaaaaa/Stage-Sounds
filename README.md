# Stage Sounds

文化祭の劇で使う BGM・効果音を、ブラウザから再生するアプリです。Node.jsやサーバー起動は不要で、`index.html` をブラウザで開いて使います。

## フォルダ構成

```text
/
├── index.html
├── style.css
├── styles/
│   ├── base.css
│   ├── settings.css
│   ├── library.css
│   ├── player.css
│   ├── dialogs.css
│   ├── responsive.css
│   └── theme-dark.css
├── js/
│   ├── state.js
│   ├── storage.js
│   ├── library-view.js
│   ├── shortcuts.js
│   ├── player.js
│   ├── audio-library.js
│   └── app.js
├── README.md
└── data/
    ├── BGM/
    └── SoundEffects/
```

## コードの見方

- `style.css` は共通スタイルの入口です。部品ごとのCSSは `index.html` から個別に読み込み、ブラウザが並行して取得できるようにしています。見た目の変更は `styles/` 内の該当ファイルで行います。
- `styles/base.css` はページ全体、`settings.css` は設定欄、`library.css` は音声カード、`player.css` は再生中の一覧、`dialogs.css` はHELPと追加画面、`responsive.css` はスマートフォン対応、`theme-dark.css` は暗い配色を担当します。
- JavaScriptは `index.html` の `<script>` の順番で読み込みます。`js/state.js` が共通データを準備し、保存・一覧・キー操作・再生・音声追加の処理を順に読み込んだ後、最後の `js/app.js` が画面を起動します。読み込み順は変えないでください。
- 固定音声の登録は `js/state.js` 冒頭の `audioLibrary` を編集します。

## 音声ファイルを追加する

### BGM・効果音を画面から追加する

1. BGM 欄の「＋ BGMを追加」または効果音欄の「＋ 効果音を追加」を押して、音声ファイルを選択します（複数選択できます）。
2. 選択したファイルが検出され、ファイル名をもとに表示名が入力されます。好きな名前に編集してください。
3. 「追加する」を押すと、選んだカテゴリに再生ボタンが追加されます。

追加した音声ファイルと表示名は、ブラウザの IndexedDB に保存され、次回このページを開いたときに自動で復元されます。元のファイルはコピー・移動・変更されません。音声はブラウザの保存領域を使うため、容量制限に達した場合やブラウザのデータを削除した場合は保存が消えることがあります。
### この機能は非推奨。

ブラウザの安全上の制限により、このアプリが `data/BGM/` や `data/SoundEffects/` フォルダを自動監視することはできません。それぞれのカテゴリにある「追加」ボタンから音声を選んでください。

### 固定リストで追加する

まず`data`フォルダを作成してください。そして、`data/BGM`,`data/SoundEffects`を作成してください。
効果音は `data/SoundEffects/` に保存し、`js/state.js` 冒頭の固定配列 `audioLibrary.soundEffects` に表示名・ファイル名・任意の説明を登録します。固定リストの BGM を使う場合は `audioLibrary.bgm` に登録します。登録後に `index.html` を再読み込みしてください。

例:

```js
const audioLibrary = {
  bgm: [
    { title: "オープニング", file: "opening.mp3", description: "幕開けの音楽" },
    { title: "静かな場面", file: "quiet-scene.wav", description: "場面転換" }
  ],
  soundEffects: [
    { title: "ドアの音", file: "door.wav", description: "ドアを開ける場面" }
  ]
};
```

`file` は各フォルダ内に置いたファイル名と一致させてください。ファイル名には日本語や空白も使えます。MP3、WAV、OGG など、利用するブラウザが再生できる形式を選んでください。複数の音声を登録する場合は、各オブジェクトの末尾にカンマを付けます（最後の項目には不要です）。

### state.jsに文化祭で使ってたやつの残骸がありますが気にしないでください。

## 操作方法

- 初回起動時に HELP が開きます。操作説明を確認して「はじめる」を押してください。
- 音声カードの再生ボタンを押すたびに、新しい `Audio` インスタンスで再生します。同じ音を連続して押すことも、異なる音を重ねることもできます。
- 音声カード左側の「⠿」をドラッグして並べ替えられます。ドラッグ操作が難しい場合は上下の矢印ボタンを使ってください。BGM・効果音ごとに順番が自動保存され、次回起動時にも復元されます。
- 各音声カードの「音量」バーで、音声ごとの音量を調整できます。再生中に変更すると、その音声の再生中インスタンスすべてにすぐ反映され、設定も次回起動時に復元されます。
- 再生中の音声は画面下部のプレイヤーに横並びで表示されます。各再生カードの音量バーは、その再生インスタンスだけに適用され、別の再生音には影響しません。この個別音量は再生中だけ有効です。
- 再生カードには音声ごとの個別停止ボタンがあり、再生位置バーをドラッグしてシークできます。複数再生中はプレイヤー欄を横にスクロールできます。
- 音声カードの「キー設定」を押してからキーボードのキーを1つ押すと、そのキーで再生できます。使用中のキーは別の音に設定できず、重複時はカードに通知されます。キー設定も次回起動時に復元されます。Ctrl・Alt・Shift・Windows/Commandキーとの組み合わせには対応していません。
- 「すべて停止」で再生中の音をまとめて停止できます。
- HELP は画面右上の「使い方」からいつでも再表示できます。
- 利用規約・プライバシーは画面下部の「利用規約・プライバシー」から確認できます。音源の権利確認や公演利用に必要な手続きは、利用者が行ってください。
- 音声ごとの音量を調整した後、全体の音量はパソコン本体またはブラウザの音量で調整してください。

## UI カラー設定

「テーマカラー」の色見本を押し、カラーピッカーから色を選びます。選択した色はすぐ画面に反映され、ブラウザの `localStorage` に保存されます。次回起動時に保存済みの色を読み込みます。ブラウザのプライベートモードや `file://` ページの保存制限によって、設定が保存されない場合があります。

## 推奨環境・注意点

- IndexedDB による音声保存を含め、最新版の Google Chrome または Microsoft Edge を推奨します。
- ローカルファイルのまま動作するため、Electron や localhost は必要ありません。`index.html` をダブルクリックして開いてください。
- ブラウザによって `file://` ページの保存の扱いが異なります。保存に失敗する場合は最新版の Chrome または Edge でお試しください。ブラウザのデータを消去すると保存済み音声も削除されます。
- 本番前に、使用するパソコン・ブラウザ・スピーカーで音声、音量、複数同時再生を確認してください。
